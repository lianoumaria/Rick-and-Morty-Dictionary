# Rick-and-Morty-Dictionary
Web Development Bootcamp Public API Project

## This website uses the remote API: [Rick and Morty](https://rickandmortyapi.com/)
This is a public API that does not require authentication and supports CORS.

### Installation
Run 
`npm i` 
to install the needed dependencies

### Start the server
Run
`node index.js`
to start the server

### Open website
Open 
http://localhost:3000 
in your browser to view the website
